## Social preview prompt

Use case: ads-marketing. Create a premium GitHub repository social preview banner for KeyPocket, a small native macOS tool for API URLs, API keys and environment variables, with local Keychain storage and CLI/MCP access for AI agents. Canvas exactly 1280 x 640 pixels, landscape 2:1. Visual identity: warm off-white #F5F4EF, deep forest green #2B6E59, near black typography, very subtle paper texture. Sophisticated restrained developer-tool editorial art direction. Large perfectly legible 'KeyPocket' on left, short line beneath verbatim 'API keys. One small home.' Small footer text 'macOS · Keychain · CLI + MCP'. Right half: beautifully lit tactile 3D rounded porcelain desktop-app tile in warm white with a simple forest-green horizontal key glyph, accompanied by two thin hovering code slips with exact text 'URL=https://api.example.com' and 'API_KEY=••••••••'. Gentle daylight, soft studio shadows, shallow dimensionality, lots of whitespace. Everything including text within 72px safe margins. Straight clean typographic alignment. No gradient blobs, no purple, no padlock, no robots, no watermarks, no unrelated brand logos, no fake security certification. The large app tile and small code slips should feel like an elegant physical still-life, not a web dashboard.

## README hero prompt

Use case: ads-marketing / product illustration. Create a polished wide README hero for KeyPocket, a small native macOS API configuration manager. Canvas 1600 x 900 pixels. Same coherent brand: warm off-white #F5F4EF background, forest-green #2B6E59, dark charcoal, subtle fine paper grain. Designed composition not screenshot. Top-left small simple green horizontal key glyph followed by 'KeyPocket'. Large heading verbatim 'Your API setup, ready for agents.' Below it a refined editorial product illustration, central macOS-style small white rounded configuration window with three subdued window-control dots and title 'Developer'; within it generously spaced precise monospaced lines 'URL=https://api.example.com/v1', 'API_KEY=demo-key', 'MODEL=example-model'. A small bottom status 'Saved locally'. This illustrative window connects with two restrained fine green branching paths to two smaller clean cards on the right titled 'CLI' and 'MCP', with respectively '> keypocket run' and 'get_connection' underneath. A small green Keychain token below the source window visually conveys local storage, labelled 'macOS Keychain'. Soft layered paper depth, extremely subtle shadows, calm confident high craft. Main window visually dominates; maintain whitespace and clear left-to-right reading order. Footer small line verbatim 'Local storage. Developer editing. Agent access.' All text accurate and legible, no real credentials, no security guarantees, no additional product features, no cloud, no robots, no purple gradients, no decorative clutter, no watermark. This is a conceptual product illustration, not an exact software screenshot.
